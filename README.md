# Rome Particle Monitoring Dashboard

Interactive web dashboard for the 2026 CPC/SMPS monitoring campaign in Rome.

The site combines CPC and SMPS particle-number data, an SMPS size-distribution heatmap, weather from Roma/Ciampino, official ARPA Lazio air-quality observations, interactive Pearson/Spearman correlations, and an animated map with wind rose and rain overlay.

The dashboard is a static GitHub Pages site. Browser-ready data are generated by exportWebData.m from the MATLAB analysis.

The particle measurement location is 41.798372, 12.515188. Weather and air-quality stations are several kilometres away; correlations do not demonstrate causation or uniquely identify an emission source.
